**Repositorio:**  
👉 [https://github.com/pakomertelo/p1](https://github.com/pakomertelo/p1)

**Descripción:**

* Carrito de compra.
* Lista de deseos mediante cookies.

* Separación básica entre lógica, estilos y scripts.

### 🔹 Proyecto 4 — UT7 DSW: Servicios y uso de APIs

**Repositorio:**  
👉 [https://github.com/pakomertelo/ut7-dsw](https://github.com/pakomertelo/ut7-dsw)

**Descripción:**  
Proyecto web desarrollado para la unidad de trabajo 7 de Desarrollo Web en Entorno Servidor. El objetivo principal es practicar el uso de servicios y APIs desde PHP, combinando varias formas de obtener y mostrar información externa.

El proyecto incluye servicios SOAP sobre una base de datos, lectura de noticias mediante RSS y consumo de la API REST de AEMET mediante un proxy en PHP. También incorpora configuración separada para la conexión con base de datos y para la clave de API.

**Funcionalidades principales:**

* Servicio SOAP en PHP.
* Cliente SOAP para consultar información.
* Consulta de datos desde base de datos MySQL/MariaDB.
* Lectura de RSS de EuropaPress.
* Consumo de API REST de AEMET.
* Uso de proxy PHP para proteger la API key.
* Manejo de respuestas JSON.
* Separación por carpetas: `aemet`, `config`, `rss`, `soap` y `css`.

**Tecnologías:**

* PHP
* HTML
* CSS
* JavaScript
* MySQL / MariaDB
* SOAP
* REST API
* RSS
* JSON
* cURL

### 🔹 Proyecto 5 — Tienda MTG

**Repositorio:**  
👉 [https://github.com/pakomertelo/proyecto-tienda-mtg](https://github.com/pakomertelo/proyecto-tienda-mtg)

**Descripción:**  
Proyecto de tienda online de cartas de Magic: The Gathering desarrollado para 2º de DAW. Incluye autenticación básica, catálogo de productos, carrito de compra, lista de deseos y sistema de valoración por estrellas.

El proyecto utiliza PHP para la parte de servidor, MySQL/MariaDB para la base de datos y JavaScript para funcionalidades dinámicas como el carrito con `localStorage` y el envío de votos mediante `fetch` sin recargar la página.

**Funcionalidades principales:**

* Login básico de usuarios.
* Usuario administrador de prueba.
* Registro automático de usuarios al iniciar sesión.
* Catálogo de cartas Magic.
* Carrito lateral usando `localStorage`.
* Lista de deseos.
* Sistema de valoración de productos de 1 a 5 estrellas.
* Envío de valoraciones con `fetch`.
* Control para evitar votos duplicados por usuario.
* Base de datos inicial mediante `init.sql`.
* Productos de ejemplo incluidos.

**Tecnologías:**

* PHP
* MySQL / MariaDB
* JavaScript
* CSS
* HTML
* LocalStorage
* Fetch API
* SQL
